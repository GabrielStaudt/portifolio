# Assets do portfólio

## Ícones

- `icons/favicon.svg`: monograma GS em ciano e violeta.
- `icons/sprite.svg`: símbolos GitHub, LinkedIn, código, dados, automação e link externo.

Os SVGs são arquivos vetoriais editáveis. Os ícones sociais identificam suas respectivas plataformas. O código dos assets próprios acompanha a licença MIT do projeto.

## Fontes

Arquivos locais fornecidos pelo Google Fonts:

- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), pesos regular e negrito. Licença em `fonts/SPACE-GROTESK-LICENSE.txt`.
- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono), peso regular. Licença em `fonts/JETBRAINS-MONO-LICENSE.txt`.

Ambas usam SIL Open Font License. Os arquivos foram baixados das distribuições oficiais do Google Fonts.

## Capturas

`screenshots/desktop/`: início, sobre mim, habilidades, projetos e contato, em viewport de 1280 × 900.

`screenshots/mobile/`: início, sobre mim e projetos em viewport de 390 × 844.

Capturas feitas no navegador a partir desta versão do site. Para atualizar, rode o build e o servidor local, confira o visual e substitua as imagens mantendo os nomes usados pelo README.

As capturas servem à documentação e não são copiadas para a publicação.

## Elementos em CSS

A malha de fundo, os brilhos e o painel de terminal são desenhados por CSS e HTML em `src/`. Não dependem de imagens externas.
